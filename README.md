# Parking-System-Management-CPP
Parking System Management using C++ and Data Structures

A **console-based Parking System Management project** implemented in **C++**, designed using core **Data Structures concepts** such as **Stack, Queue, Linked List**, and **File Handling**.

This project simulates a real-world parking system featuring **VIP parking**, **waiting queues**, **multi-level parking**, and **dynamic fee calculation**.

---

## 📌 Features

- ✅ Multi-level parking system
  - Level 1: Cars & Trucks
  - Level 2: Bikes & Electric Vehicles
  - VIP Slots
- ✅ VIP priority handling
- ✅ Waiting queue management
- ✅ Time-based parking fee calculation
- ✅ Double charge after booked time expires
- ✅ Parking history management using linked list
- ✅ Admin panel with:
  - Parking overview
  - Ticket search
  - Revenue tracking
  - Rate modification
- ✅ File handling to save parking history

---

## 🧠 Data Structures Used

| Data Structure | Usage |
|----------------|-------|
| Stack | Parking slots (LIFO) |
| Queue | Waiting & VIP queues |
| Linked List | Parking history |
| File Handling | Save history to file |
